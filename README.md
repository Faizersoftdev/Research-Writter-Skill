# School-Style IMRAD Research Writer

A reusable writing skill distilled from the Hourly thesis workflow and reference manuscript pages.

## Files
- `SKILL.md`: primary reusable skill instructions and boundaries.
- `references/style-guide.md`: general-to-specific school-format conventions.
- `templates/introduction-and-methods.md`: copy-ready structured manuscript skeleton.
- `templates/starter-prompt.md`: quick prompt for applying the skill to a new study.
- `references/quality-checklist.md`: accuracy and formatting audit.
- `references/hourly-example.md`: context-only mapping to demonstrate application of this format.

## Use
Keep these files together when adding them to any environment that supports folder-based skills, or attach/paste `SKILL.md` and relevant supporting files into a new ChatGPT conversation. The starter prompt can be used with a new study. This repository does **not** automatically install or permanently enable a skill in your ChatGPT account.

The skill intentionally uses school-requested superscript footnotes plus APA-style bibliographic entries. This is a local hybrid convention; standard APA 7 in-text citation is author–date.
