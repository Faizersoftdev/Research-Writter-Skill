# Pre-delivery manuscript audit

- [ ] Scope correct: Introduction/Methods only when requested; no fabricated Results/Discussion.
- [ ] Opening of each section moves from general explanation to study-specific facts.
- [ ] Every study fact comes from supplied materials or verified cited research; observation and interview labels are accurate.
- [ ] Claims about existing studies are narrower than or equal to what the sources actually demonstrate.
- [ ] Title, system type, users, platform, target setting and objectives are consistent across sections.
- [ ] Objective bullets start 'To ...' and map to real system features or evaluation activities.
- [ ] SDG and evaluation model included only when selected or supported.
- [ ] Citations sequential, sourced, deduplicated; APA-styled entries complete, no extra annotations or tracking parameters.
- [ ] Methodology is the user-approved model, with exact approved stage labels.
- [ ] Each stage names concrete actions for this study; tense matches actual completion status.
- [ ] RAD diagram marker/caption occurs between stage-introduction sentence and stage-by-stage explanation.
- [ ] Hardware and software tables have explicit standalone insertion markers, captions, and specific prose grounded in supplied specifications.
- [ ] Core offline requirements distinguished from optional AI/website/update internet requirements where relevant.
- [ ] Diagram narrative matches the real user-provided Activity Diagram; appendix label and cross-reference match.
- [ ] Evaluation characteristics, participant count, instrument and formulas are not invented.
- [ ] Figure/table numbers and captions match the final manuscript sequence/template.
- [ ] Changed only the requested scope when user asked for a narrow edit.
- [ ] No accidental carry-over of example study names, locations, features, conclusions or source citations.
